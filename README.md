# Pipeline ETL com Python - Santander Dev Week 2023

## 📋 Descrição do Projeto
Este projeto demonstra um pipeline ETL (Extract, Transform, Load) utilizando Python e a biblioteca Pandas, desenvolvido para o desafio da Santander Dev Week na DIO.

## 🛠️ O que foi feito:
1. **Extract (Extração):** Simulação de extração de dados de clientes (Nome e Saldo).
2. **Transform (Transformação):** Lógica em Python para gerar mensagens de marketing personalizadas baseadas no saldo de cada cliente.
3. **Load (Carregamento):** Exportação dos dados transformados para um arquivo `.csv` pronto para uso.

## 🚀 Tecnologias Utilizadas
*   Python 3
*   Biblioteca Pandas
*   VS Code

## 💡 Alternativa Implementada
Segui a **Alternativa 2** proposta no desafio (Manipulação de Arquivo CSV), focando na lógica de fluxo de dados.
